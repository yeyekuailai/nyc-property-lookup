# NYC Property Lookup for GitHub Pages

Static site for searching New York City property information by address or BBL. It reads NYC Planning GeoSearch and the public ArcGIS service used by the Property Information Portal directly from the browser. NOPV links point to the NYC Department of Finance using the resolved BBL.

Live site: https://yeyekuailai.github.io/nyc-property-lookup/

GitHub Pages does not run server code. The site links to the 2026–27 annual NOPV PDF and to the official BBL property page for revised and historical notices. It does not save queries or PDFs.

Publish this directory under any GitHub Pages repository. No build step, API key, or Netlify service is required.
