# NYC Property Lookup for GitHub Pages

Static site for searching New York City property information by address or BBL. It reads NYC Planning GeoSearch and public NYC data services directly from the browser. Downstream searches use the resolved borough, block, and lot.

Live site: https://yeyekuailai.github.io/nyc-property-lookup/

The result shows county and building data, links to the 2026–27 NOPV, queries both city Certificate of Occupancy datasets, and opens DOB and HPD building records including complaints, violations, charges, and litigation.

Publish this directory under any GitHub Pages repository. No build step, API key, or Netlify service is required.
